# Changelog

All notable changes to this plugin will be documented here.

## 1.0.0 — initial release

- Added the `leadjourney` MCP server pointing at LeadJourney's hosted Streamable HTTP endpoint (`https://api.leadjourney.io/mcp`).
- Auth uses OAuth with LeadJourney sign-in — no API key or client ID to configure.
- Added the `leadjourney-tracking-setup` skill for installing and verifying the tracking script in a website's codebase.
