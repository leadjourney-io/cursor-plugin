# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/leadjourney-io/cursor-plugin/security/advisories/new), or by email to hello@leadjourney.io with "Security" in the subject.

We aim to acknowledge reports within 2 business days.

## Scope

This repository holds the Cursor plugin manifest, MCP configuration and skills. The LeadJourney MCP server at `https://api.leadjourney.io/mcp` and the LeadJourney app are in scope for reports too: use the same channels.
